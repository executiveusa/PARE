# PARÉ Journal — Agent Publishing Contract

The Journal is an agent-assisted editorial surface, not an autonomous spam feed.

## Purpose
Publish evidence-backed field notes about sovereign software, agentic design, Loop Engineering, project ownership, model/runtime architecture, and real PARÉ builds.

## Voice
- restrained, precise, editorial;
- premium design-studio language rather than generic SaaS marketing;
- short assertions supported by concrete systems, builds, or receipts;
- no breathless AI superlatives;
- no fabricated customer outcomes, benchmarks, integrations, partnerships, awards, or launch status.

## Agent workflow
1. Read the active PARÉ ICM/Loop run and current release evidence.
2. Choose one idea with a real receipt.
3. Draft one article and a 40–70 word index abstract.
4. Verify every product/runtime claim against the exact current repo/runtime evidence.
5. Mark unverified future capabilities as roadmap, not shipped capability.
6. Run a fresh editorial critic for clarity, originality, factual support, and brand fit.
7. Human approval is required before public publishing until a narrower standing publishing policy exists.

## Required article metadata
- title
- slug
- date
- type: field-note | case-study | architecture | release
- status: draft | verified | published
- evidence revision(s)
- summary
- body

## Distribution derivative
After a post is verified, an agent may generate drafts for LinkedIn, Instagram carousel/reel script, Facebook, X/Threads, and MACS Digital Media proof-of-concept distribution. External posting remains gated unless explicitly authorized.
