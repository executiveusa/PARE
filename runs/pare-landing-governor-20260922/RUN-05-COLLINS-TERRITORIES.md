# Territory A — EDITORIAL REDUCTION
Type: restrained
Recommendation: PRIMARY

## Governing idea
A serious editorial object that removes visual noise as aggressively as the product removes operational noise.

## Strategic connection
PARÉ's difference is not “more AI.” It is fewer visible layers between idea and outcome. The composition should feel edited, authored, and controlled.

## Customer effect
“I understand this immediately, it feels unusually considered, and I trust the product more because it does not oversell itself.”

## Grid
- asymmetrical 12-column editorial grid
- dominant left alignment
- intentional off-grid crossword
- large fields of negative space
- product proof spans the grid rather than living in a card

## Typography
- modern grotesk/sans for primary communication
- mono only for system labels and machine interfaces
- extreme scale contrast used sparingly
- no ornamental luxury serif

## Color
- warm ivory / paper
- near-black
- restrained stone/graphite secondary values
- one temporary signal color only if needed for active system state

## Imagery
- authentic PARÉ interface capture
- real generated artifacts
- cropped like editorial evidence, never floating device mockups
- no generated decorative hero image

## Motion
- crossword/Fusion is the single signature interaction
- product proof may use subtle state progression
- everything else nearly static
- no decorative parallax

## Navigation
PARÉ | How it works | Try PARÉ

## Signature moment
Crossword resolves to PARÉ; product truth appears immediately under/alongside the resolved mark.

## Accessibility risks
Very large type and asymmetrical composition can create reflow issues; must preserve linear reading order.

## Performance risks
Low.

## Imitation risk
Low if the crossword and reduction rhythm remain proprietary.

## Commercial advantage
Strongest balance of premium perception, comprehension, speed, and product credibility.

# Territory B — KINETIC LEDGER
Type: expressive

## Governing idea
The product behaves like a live operational ledger: intention enters, complexity is reconciled, verified output remains.

## Strategic connection
Highlights the agent/runtime system and proof-first methodology without becoming a dashboard.

## Customer effect
“This is an active system, not just a design tool.”

## Grid
- narrow persistent index rail
- changing main stage
- timeline/proof markers
- product action states become compositional anchors

## Typography
- condensed display sans for transitions
- neutral sans body
- mono for state/proof receipts

## Color
- black/ivory base
- one electric verification signal
- state color appears only during active/proved moments

## Imagery
- real run receipts
- code/interface fragments
- output crops
- verification evidence

## Motion
- scroll advances through Understand → Reduce → Create → Critique → Prove
- state changes are kinetic
- crossword still opens the experience but hands off into the ledger rhythm

## Navigation
Minimal top nav plus persistent progress index after hero.

## Signature moment
A real PARÉ run becomes a live editorial timeline and resolves into verified output.

## Accessibility risks
State/progress motion can become noisy or overly technical.

## Performance risks
Medium.

## Imitation risk
Medium; operational timelines are common unless art direction remains distinctly PARÉ.

## Commercial advantage
Makes the agentic/verification system easier to understand for technical and agency buyers.

# Territory C — LIVING CROSSWORD
Type: experimental

## Governing idea
The entire site is one evolving semantic field. Words intersect, disappear, and reform as the visitor moves from concept to product.

## Strategic connection
Extends the crossword from a hero effect into the full visual language of PARÉ.

## Customer effect
“This product has an identity I have not seen elsewhere.”

## Grid
- visible modular word grid
- content blocks inherit crossword intersections
- section boundaries can be formed by type rather than boxes

## Typography
- mono/grotesk hybrid system
- words become structural geometry
- large typographic intersections

## Color
- ivory/black
- grayscale transparency
- no gradient identity

## Imagery
- interface/product captures embedded as “filled cells” inside the semantic grid
- output artifacts interrupt the word field

## Motion
- words subtract and reorganize between sections
- only one motion grammar: remove → converge → resolve
- reduced-motion fallback becomes static editorial grid

## Navigation
PARÉ + Try PARÉ fixed; section orientation appears through grid labels.

## Signature moment
The initial crossword is not isolated; the same reduction grammar reappears in product proof and ownership.

## Accessibility risks
Highest of the three. Must not require spatial decoding for comprehension.

## Performance risks
Medium/high if overbuilt.

## Imitation risk
Lowest conceptually because the interaction is tightly tied to the name, but highest risk of becoming self-indulgent.

## Commercial advantage
Strongest memorability and award-level distinctiveness if kept disciplined.

# Recommendation
Choose **Territory A — Editorial Reduction** for the production direction.

Why:
- current Playwright proof shows the reduced structure already works;
- the site needs trust and product clarity more than additional spectacle;
- the crossword is already a proprietary signature moment;
- the protocol explicitly warns against long intros, unnecessary motion, and visual polish that hides the offer;
- authentic product proof will carry more persuasive weight than another decorative system.

Borrowing pieces from B or C should happen only after Territory A is selected and only when they directly strengthen proof. Do not average all three.
