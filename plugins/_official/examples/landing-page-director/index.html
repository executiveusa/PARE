PARE / Landing Page Director

Strategy before styling.

An evidence-led landing-page workflow that grills the objective, locks one conversion path, builds from a defensible creative idea, and refuses release until independent adversarial review passes.

01

Grill

Resolve the outcome, visitor, product truth, CTA, proof, objections, constraints, and failure conditions. Do not build yet.

02

Inspect + prove

Read the existing product, brand system, page, analytics, and evidence. Build claims and reference ledgers. Never invent proof.

03

Choose a territory

Create restrained, expressive, and experimental directions. Extract principles from references; never clone visual expression.

04

Lock + build

Freeze the conversion and Design Lock, then build the shortest complete journey: hero, demonstration, proof, objection, CTA, confirmation.

05

Attack it

Eight independent reviewers test conversion, clarity, creative authorship, slop, mobile, accessibility, production, and sovereignty.

06

Repair + release

Fix every P0/P1, rerun the complete Gauntlet, verify real mobile behavior and the CTA result, then record rollback evidence.

No vibe-code slop.

No generic SaaS hero, fake proof, decorative complexity, visual cloning, or compressed-desktop mobile.

The builder cannot approve itself.

Conversion must score at least 9/10; overall, usability, visual design, originality, and accessibility at least 8.5/10, with zero critical failures.
