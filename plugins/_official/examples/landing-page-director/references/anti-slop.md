# Anti-slop release gate

This gate exists to stop generic AI-generated marketing design before it reaches production. It is a failure detector, not a style preset.

## Automatic rejection patterns

Reject and redesign when the page relies on any of these without a product-specific reason:

- generic centered SaaS hero;
- blue/purple gradient as substitute for identity;
- glass cards or frosted panels as default decoration;
- default bento grid;
- three equal feature cards with interchangeable icons;
- rounded rectangles everywhere;
- glowing orbs, blobs, mesh gradients, AI brains, neural-network decoration;
- a dashboard screenshot pasted into a gradient with no explanatory role;
- meaningless 3D objects or motion;
- arbitrary display serif used only to signal “luxury”;
- stock photography presented as product evidence;
- fake testimonials, logos, customer counts, awards, integrations, or metrics;
- vague verbs such as transform, unlock, empower, reimagine, revolutionize, or supercharge when concrete language is possible;
- CTA labels such as `Get Started`, `Learn More`, or `Submit` when they hide what happens next;
- decorative scroll effects, marquees, pills, badges, or carousels with no information job;
- hover-only discovery or controls;
- mobile produced by shrinking or stacking the desktop page without re-composition;
- adding a component because it exists in a library rather than because it advances understanding, belief, action, recovery, or proof.

## Interchangeability test

Replace the brand name and nouns with those of a different SaaS product. If the page still works with almost no structural change, the creative idea is too generic.

## Product-proof test

Ask whether a real interface, result, input/output transformation, customer artifact, measured outcome, demonstration, or verified evidence could replace atmospheric decoration. Prefer the stronger proof.

## Copy test

Every major sentence must earn its space by doing one of these jobs:

- identify the category;
- make the outcome concrete;
- explain the mechanism;
- establish relevance;
- reduce an objection;
- supply proof;
- make the next action explicit.

Delete or rewrite copy that exists only to sound impressive.

## Reference test

References are evidence for principles, not a tracing layer. Record what is being learned and what must not be copied. Do not reproduce another site's distinctive composition, copy, imagery, motion choreography, illustration language, or brand signature.

## Final decision

The Slop Hunter returns `PASS` only when the page has a defensible governing idea tied to this product, real information hierarchy, specific language, honest proof, purposeful components, and a mobile composition that appears intentionally designed rather than responsively collapsed.
